# 最小可运行版本实施计划

## 目标

在保留现有纯 HTML 原型作为需求参考的前提下，交付一个可独立运行的模块化单体：Java 后端负责认证、权限、业务规则、展示字段和数据持久化；浏览器端只负责平台导航、交互和 API 数据渲染。生产数据库使用项目自建 MySQL，不迁移原型数据。

## 技术基线

- Java 21、Spring Boot 3.5.16、Maven
- Spring MVC、Spring JDBC、Spring Security、Spring Session JDBC
- MySQL 8.4 LTS、Flyway 数据库版本管理
- 无构建依赖的 HTML/CSS/ES Modules 前端，由单体服务托管
- Actuator + Micrometer Prometheus
- Docker Compose 本地/试运行，GitHub Actions 构建与发布镜像

## 实施切片

### 1. 工程骨架与契约

验收条件：Maven 工程可编译；应用配置不含明文生产秘密；统一 API 错误结构已定义。

验证：`./mvnw test`。

### 2. 认证与账号

验收条件：启动时可通过环境变量创建首个管理员；支持登录、退出、当前用户查询；密码使用 Argon2；写操作受 CSRF 保护；会话存储在数据库。

验证：认证集成测试覆盖未登录、成功登录、错误密码、权限拒绝和退出。

### 3. 临床管线最小业务闭环

验收条件：管理员/业务用户可创建研究项目；所有已登录用户可读取管线汇总和列表；展示状态文案、数量统计由后端返回。

验证：业务服务单元测试和 API 集成测试。

### 4. 平台壳与子 Tab

验收条件：未登录显示登录页；登录后进入平台壳；“临床研发管线”作为子 Tab；“平台管理”仅管理员可见；页面不自行推导业务文案。

验证：前端脚本静态语法检查、后端端到端 HTTP 冒烟验证。

### 5. 动态配置

验收条件：运行参数分为需重启的基础设施配置与可在线修改的业务配置；管理员可通过 API 更新业务配置并立即生效；变更记录操作者和时间。

验证：配置 API 权限和即时读取测试。

### 6. 云部署与可运维性

验收条件：提供非 root 容器、MySQL Compose、健康探针、Prometheus 抓取配置、告警规则、CI/CD 工作流、备份恢复及发布回滚手册。

验证：配置文件静态检查、Maven 打包、应用本机启动和健康检查；本机无 Docker 时记录容器验证边界。

## 不在 MVP 范围

- 原型/localStorage 数据迁移
- 微服务、服务注册发现、消息队列
- 企业 SSO、多因素认证、复杂组织架构
- 完整月报、风险、里程碑、团队矩阵等原型全部功能
- Kubernetes（达到明确规模或高可用需求后再评估）
